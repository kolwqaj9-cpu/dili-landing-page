One public book. One question. Page cites.

  1. You already published a manual or a parts catalog on your own support site.
  2. We pick one question that is actually answered in that book.
  3. We build a private lookup that shows the steps and the page numbers.
  4. You open your own PDF and check. If a cite is wrong, we stop and fix it.
  5. If a shop would use it, we can do more pages from the same book the same way.

How the lookup answers

The page ships with the phrases and the cross-references written at build time, from that one book. A query is matched in your browser against those written phrases. Nothing is sent to a language model, nothing is generated on the fly, and a code that is not in the book comes back empty rather than guessed at.

That is deliberate. A lookup that invents a fault code is worse than no lookup at all.

Why the trial link is private

The trial page is served on a noindex path, so it does not mix with your live site and does not compete with it in search. It is a working sample, not a page we publish under your name.

What you need on your side

Nothing. You keep the PDF where it already is. We only ever read what you have already published.

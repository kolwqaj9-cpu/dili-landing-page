Compressor shuts down with air demand present. First checks?

From Table 7-3, troubleshooting guide

  1. No fuel. Check the fuel gauge and add fuel if necessary.
    出处：原手册第 70 页，Table 7-3 第一行
  2. Compressor discharge temperature switch is open. Cooling air flow is insufficient — clean the cooler and check ventilation. Also listed: low fluid sump; dirty compressor fluid filter; thermostatic element; defective discharge temperature switch. The electrical section says this switch shuts the compressor down if compressor temperature exceeds 250°F (121°C).
    出处：原手册第 70 页 Table 7-3；第 29 页电气系统
  3. Then the same table: electrical control fault — read the controller message bar; low DEF — check DEF gauge; exhaust aftertreatment fault — check active engine codes in the Engine Operator’s Manual.
    出处：原手册第 70 页 Table 7-3
